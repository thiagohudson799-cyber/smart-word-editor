# 📝 Smart Word Editor (AI-Powered)

Um editor de texto web inteligente com foco na produtividade, formatação ABNT simplificada e **autocorreção ortográfica e gramatical em tempo real** via Inteligência Artificial.

## 🚀 Funcionalidades Planeadas
- ✍️ Editor WYSIWYG moderno e responsivo.
- 🤖 Autocorreção gramatical inteligente em segundo plano.
- 📐 Formatação ABNT em 1 clique (margens, espaçamentos e fontes).
- 🖼️ Gestão fluida de imagens sem desconfigurar o layout do documento.

## 🛠️ Tecnologias
- **Frontend:** React, Tiptap Editor, TailwindCSS
- **Backend:** Node.js / Express (ou Python FastAPI)
- **AI Integration:** APIs de LLM para processamento de linguagem natural
